# Guide Direction — ORYA

1. **Connexion** : e-mail + mot de passe, puis code MFA (application d'authentification). À la première connexion, scanner le QR code et conserver les codes de secours.
2. **Tableau de bord** (`/dashboard`) : effectifs, absences du jour, justificatifs en attente, export CSV/XLSX.
3. **Imports** (`/imports`) : déposer le fichier élèves/parents, vérifier l'aperçu et les erreurs, puis valider. Un code Massar existant n'est jamais remplacé.
4. **Comptes** : inviter professeurs et parents ; l'invitation expire, elle peut être renvoyée.
5. **Absences et justificatifs** (`/justifications`) : accepter ou refuser chaque justificatif, avec motif en cas de refus.
6. **Massar** (`/massar`) : contrôle des codes, puis export « format ORYA compatible pour saisie Massar ». Ce n'est **pas** une connexion ni un format officiel Massar : vérifier les colonnes avant saisie.
7. **Abonnement** (`/billing`) : plan, limites et statut. Aucun paiement en ligne n'est actif pour le pilote.
8. **Sécurité** : se déconnecter sur un poste partagé ; toute action sensible est journalisée.
