# Guide Professeur — ORYA

1. **Activation** : ouvrir le lien d'invitation, choisir un mot de passe, puis se connecter.
2. **Faire l'appel** : choisir sa classe et la séance, marquer Présent / Absent / Retard, puis enregistrer. Une séance enregistrée peut être corrigée tant qu'elle n'est pas verrouillée par la direction.
3. **Classes visibles** : seules les classes qui vous sont affectées pour l'année scolaire en cours apparaissent. En cas d'oubli, contacter la direction.
4. **Sur téléphone** : l'appel fonctionne sur mobile ; vérifier le message « Appel enregistré » avant de quitter.
